## 04-1 로지스틱 회귀
- https://colab.research.google.com/drive/1u3hpWHfIRSw6AUdt4hquxboX2jVTwRXM

### 요약

1.  **데이터 전처리**: 원본 데이터를 모델 학습에 적합한 형태로 변환하는 과정(특성-타겟 분리, 훈련-테스트 세트 분리, 특성 스케일 조정)의 중요성을 이해해야 합니다.
2.  **k-최근접 이웃 (k-NN) 분류**: k-NN 모델이 어떻게 예측하고 확률을 계산하는지 (이웃의 비율) 이해하고, 예측의 근거를 찾는 방법(`kneighbors()`)을 알아야 합니다.
3.  **로지스틱 회귀의 원리**: 이진 분류에서 시그모이드 함수를 사용하여 선형 모델의 출력을 0과 1 사이의 확률로 변환하는 과정을 이해해야 합니다.
4.  **계수(Coefficient)와 절편(Intercept)의 의미**: 로지스틱 회귀에서 학습된 `coef_`와 `intercept_`가 각 특성의 중요도와 모델의 바이어스를 어떻게 나타내는지 이해해야 합니다.
5.  **결정 함수 (Decision Function)**: `decision_function()`이 시그모이드(이진 분류) 또는 소프트맥스(다중 분류)를 적용하기 전의 원시 점수(raw score)를 나타낸다는 것을 알아야 합니다.
6.  **다중 분류 확장**: 로지스틱 회귀가 '일대다(One-vs-Rest)' 방식을 통해 어떻게 여러 클래스를 분류할 수 있는지, 그리고 소프트맥스(Softmax) 함수가 다중 클래스 확률을 계산하는 데 어떻게 사용되는지 이해해야 합니다.
7.  **하이퍼파라미터 튜닝**: `LogisticRegression`에서 `C`와 `max_iter` 같은 하이퍼파라미터가 모델의 성능과 학습 과정에 어떤 영향을 미치는지 (`C`는 규제 강도, `max_iter`는 수렴 횟수)를 유의해서 봐야 합니다.
8.  **모델 평가**: `score()` 메서드를 통해 훈련 세트와 테스트 세트에서의 모델 성능을 비교하고, 과대적합(Overfitting)이나 과소적합(Underfitting) 여부를 파악하는 방법을 알아야 합니다.

이 노트북은 k-NN과 로지스틱 회귀라는 두 가지 중요한 분류 알고리즘을 비교하고, 특히 로지스틱 회귀의 내부 동작 원리(시그모이드, 소프트맥스, 결정 함수, 계수)를 이해하는 데 중점을 둡니다. 각 단계의 코드 실행 결과와 함께 설명을 따라가며 개념을 명확히 하는 것이 중요합니다.

## 04-2 확률적 경사 하강법(SGD)
- https://colab.research.google.com/drive/10mNaTgqFWJtP44qYBVW7C7FpTWz2E3l5

### 요약

이 문서는 `SGDClassifier`를 사용한 확률적 경사 하강법 기반 분류 모델 훈련 과정을 상세하게 다루고 있습니다. 다음은 이 문서를 통해 배울 수 있는 주요 내용입니다.

1.  **데이터 로드 및 전처리**: 
    *   `pandas` 라이브러리를 사용하여 CSV 파일(`fish_csv_data`)에서 물고기 데이터를 로드하고 `DataFrame`으로 관리합니다.
    *   입력 특성(`Weight`, `Length`, `Diagonal`, `Height`, `Width`)과 타겟(`Species`)을 분리하여 모델 훈련을 위한 데이터를 준비합니다.
    *   `train_test_split`을 사용하여 데이터를 훈련 세트와 테스트 세트로 나눕니다. 이는 모델의 일반화 성능을 평가하는 데 필수적입니다.
    *   `StandardScaler`를 사용하여 특성 데이터를 표준화합니다. 이는 경사 하강법 기반 모델의 수렴 속도와 성능을 향상시키는 데 중요한 단계입니다.

2.  **`SGDClassifier` 모델 이해**: 
    *   `sklearn.linear_model` 모듈의 `SGDClassifier`는 확률적 경사 하강법을 사용하여 선형 분류 모델을 훈련하는 데 사용됩니다.
    *   **`loss` 매개변수**: `loss='log_loss'`는 로지스틱 회귀와 동일한 손실 함수를 사용하며, `loss='hinge'`는 서포트 벡터 머신(SVM)과 같은 힌지 손실 함수를 사용합니다.
    *   **`max_iter` 매개변수**: 모델 훈련 시 전체 데이터를 반복할 에포크(epoch)의 최대 횟수를 지정합니다. `ConvergenceWarning`이 발생할 경우, 이 값을 늘리거나 `partial_fit`을 사용하여 점진적으로 훈련할 수 있습니다.
    *   **`random_state` 매개변수**: 난수 시드를 고정하여 실험의 재현성을 보장합니다.

3.  **모델 훈련 및 평가**: 
    *   `fit()` 메서드를 사용하여 모델을 훈련 세트에 맞춥니다.
    *   `partial_fit()` 메서드를 사용하여 모델을 점진적으로 훈련하고, 이미 훈련된 모델에 추가적인 훈련을 적용할 수 있습니다. 이는 특히 대규모 데이터셋이나 온라인 학습 시 유용합니다.
    *   `score()` 메서드를 사용하여 훈련 세트와 테스트 세트의 정확도(accuracy)를 평가합니다.
    *   훈련 에포크에 따른 훈련 및 테스트 정확도 변화를 `matplotlib`을 사용하여 시각화하여 모델의 과대적합 또는 과소적합 경향을 분석합니다.

4.  **과대적합 및 과소적합 방지**: 
    *   에포크가 증가함에 따라 훈련 세트 정확도는 높아지지만, 테스트 세트 정확도는 어느 시점부터 정체되거나 감소할 수 있습니다. 이는 과대적합의 징후입니다.
    *   적절한 `max_iter` 값을 설정하거나 `partial_fit`을 사용하여 훈련 과정을 모니터링하고, 테스트 세트의 성능이 최대가 되는 시점에서 훈련을 멈추는 것이 중요합니다 (조기 종료).
    *   `tol=None` 설정은 `max_iter`에 도달할 때까지 훈련을 계속하며, `tol` 값을 설정하면 특정 조건(손실 함수의 변화가 일정 값 이하)에서 조기 종료될 수 있습니다.

이 문서를 통해 `SGDClassifier`의 기본적인 사용법, 모델 훈련 과정, 그리고 모델 성능 최적화를 위한 주요 매개변수 설정 및 고려 사항에 대한 실질적인 이해를 얻을 수 있습니다.
